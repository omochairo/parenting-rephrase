# 育児の言い換え - 気づきの言葉がけ

育児の様々なシーンで使える「ポジティブな言い換え」を集めたWebアプリケーションです。
押しつけがましくなく、気づきを与えることを目的としています。

## 特徴

- 🔍 **リアルタイム検索**: 言いがちな言葉（例:「早くして」）や場面で検索。語尾まで打って見つからないときは語幹で探し直す
- 💡 **3つの言い換え提案**: 「共感・行動・論理」の3タイプで多角的にアドバイス
- 📚 **45場面・約270通りの言い方**: 日常、トラブル、感情など幅広いシーンをカバー（同じ場面の言い方は1枚のカードにまとめて表示）
- 📂 **カテゴリー・場面・年齢・気分で絞り込み**
- 🆘 **いま困ってるモード**: 深呼吸のガイドと、焦っている場面の言い換えを大きな文字ですぐ表示
- 📋 **タップでコピー / 共有**: 言い換えをタップでコピー。LINE・X・Threads・端末の共有メニューで送れる
- 🌸 **今日使えた！記録**: 実際に使えた回数を今週・今日の単位で表示
- ❤️ **お気に入り機能**: 気になる言い換えを保存（ブラウザに保存されます）
- 📱 **PWA**: ホーム画面に追加でき、一度開けばオフラインでも使える
- 🚀 **完全動作**: サーバー不要で動作する静的アプリケーション

## 技術スタック

- React
- TypeScript
- Vite
- Vanilla CSS (変数ベースのデザインシステム)

## セットアップ手順

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

## ビルドとデプロイ

このプロジェクトは静的サイトとしてデプロイ可能です。

### ビルドコマンド

```bash
npm run build
```

ビルドが完了すると `dist` ディレクトリにファイルが生成されます。

### デプロイ方法

#### Netlify / Vercel / Cloudflare Pages

1. リポジトリをGitHubにプッシュ
2. 各ホスティングサービスと連携
3. 以下の設定でデプロイ:
   - Build command: `npm run build`
   - Publish directory: `dist`

#### GitHub Pages

プロジェクトの設定によっては `vite.config.ts` の `base` 設定が必要になる場合があります。
現在の設定はルート (`/`) での公開を想定しています。

## ディレクトリ構成

- `src/components`: UIコンポーネント
- `src/data.ts`: 言い換えデータ（場面ごとのテンプレートから生成）
- `src/types.ts`: TypeScript型定義
- `src/index.css`: グローバルスタイルとデザインシステム
- `src/App.css`: アプリケーション固有のスタイル
